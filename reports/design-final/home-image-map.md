# Homepage image map

The final homepage uses each primary photo once. Where the local asset pool did not contain a semantically correct cup-fan, corrugated cross-section, insert, or unbranded finished-packaging photograph, a small CSS technical visual is used instead of an ambiguous or unapproved image.

The machine mark visible in the Hero photo still requires company approval. A future reshoot should provide a clean, unbranded automatic-feeding image plus dedicated cup-fan, corrugated-section, insert, packaging-set, and quality-inspection photographs.

The machine-readable mapping, crop rationale, image kind, accessibility context, and reuse check are recorded in `home-image-map.json`.
